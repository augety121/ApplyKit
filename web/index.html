APPLYKIT GUIDE

让材料准备，少一点折腾。

本地处理 · 不覆盖原件 · 真实校验

软件只在 127.0.0.1 上交换本地数据。原材料缓存、预览与密码不发送到互联网；正常关闭后清理工作缓存。输出文件由你保留。

一次顺手的导出

① 添加并勾选材料。② 需要时打开编辑器，裁剪或旋转，保存方案。③ 直接输入数值，选择 KB / MB，也能保存常用预设。④ 开始导出，逐个检查结果。

大小是怎样判断的？

KB = 1,000 字节；MB = 1,000,000 字节。上限为严格小于，编码通常瞄准上限的 95%。可以输入 500 KB、0.8 MB、1.5 MB 等，范围为 1 KB～100 MB。清晰度底线内不能达标时明确报错，不生成“假合格”文件。

“更小”和“转换完成”不是同一件事

纯压缩不会变大；原图已达标但无法再缩小时，可原字节保留。图片编辑或格式转换默认也要求小于原件；可在更多设置中取消此约束，但上传上限依然有效。编辑无法完成时不会用未编辑原图冒充结果。PDF 转图片可能比文字型 PDF 大。

裁剪与图片编辑

PDF 预览按需加载当前页；最终按选定 DPI 重新渲染。图片支持自由框选、固定比例、旋转、水平/垂直翻转、去白边、撤销与批量应用。自动去白边可能识别不到极浅文字，提交前务必检查。没有手动框选的 PDF 页保留整页。

格式与保护

支持 JPG、JPEG、PNG、静态 GIF。动态 GIF 会拒绝处理，不静默丢帧。新编码的透明图片合成白底；不提供透明度保留、OCR、图片修复或数字签名保真。扫描 PDF 压缩和图片合并 PDF 生成图像型 PDF，不保留可搜索文本层。

运行要求与诊断

Windows 10 / 11 x64，已安装 Microsoft Edge 或 Google Chrome。PDF 使用系统 Windows.Data.Pdf 与 Windows PowerShell 5.1；不需要 Python、Node.js 或编译环境。界面由独立的浏览器应用窗口承载，程序包没有内置浏览器内核。
