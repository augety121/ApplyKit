- 保留清晰优先策略的质量底线、显式 PNG 格式、取消处理、原件字节和 PDF 全部页面；默认策略正常尝试失败后才降低质量/分辨率，必要时自动格式转 JPG。

当前测试报告：`windows-acceptance.json`；界面证据：`ui-v222-pdf.png`。图片导出已通过实际操作及文件字节数验证；截图保存接口产生的截断图片不作为证据。

验证边界：用户没有提供本次失败的原始图片/PDF，本次使用合成高细节图及扫描 PDF 复现。达标不等于文字必然可读，100 KB 尤其是多页 PDF 应人工放大检查；大量页面或极小上限仍可能无法同时满足保留全部页面与最小输出尺寸。PDF 重建不保留文本层/签名，沿用明确同意控件。Jev 1.14.0 仅比较合成提示文案，未上传私有材料。Impeccable context 因缺少引擎与缓存目录权限未运行，依据已读文案规范和现有 UI 文档完成此次小范围修改。

## 验证边界

Windows.Data.Pdf 和最终 EXE 的本地服务已实际运行；界面使用内置浏览器验收。系统 Edge/Chrome 独立应用窗口的标题栏、所有 Windows 显示缩放比例及文件夹选择器没有逐一进行人工验收。内置浏览器文件选择器在后续操作出现连接超时，因此图片界面流程使用内置合成示例完成；该限制不影响本地引擎测试。
