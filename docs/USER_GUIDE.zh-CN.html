ApplyKit 2.2.0

投递材料助手 · PDF / 图片裁剪、转换、压缩与大小校验

最快上手

首次使用可点击“载入示例，体验完整流程”。文件列表与导出结果可切换查看。PDF 自动去白边可预览识别效果，并通过“保留边距”选择 0～20 mm。

1添加 PDF 或图片
2需要时裁剪、旋转、去白边
3输入 200 KB / 500 KB / 1.5 MB 等上限
4导出后逐个预览检查

所有材料在本机处理；每次导出新建结果目录，不覆盖原件。

四个工具

工具用途
PDF 转图片逐页导出 JPG/JPEG/PNG/GIF，可自动/统一/手动裁剪白边。
图片处理压缩、格式转换、裁剪、固定比例、旋转、翻转、去白边、最长边。
图片合并 PDF按队列顺序生成一份 PDF，大小上限作用于整份文件。
扫描 PDF 压缩保留页数重新渲染为图像型 PDF，适合扫描件。

自定义大小

大小输入框不再固定 2 MB。支持 1 KB～100 MB，可切换 KB/MB，也可以输入小数，例如 0.8 MB、1.5 MB。ApplyKit 按十进制字节计算，2 MB 是严格小于 2,000,000 bytes，新编码通常瞄准 95% 上限。

纯图片压缩必须比原文件小。如果原件本身已经达标，而重新编码无法再变小，软件会明确显示“保留原件”，不会把没变小说成压缩成功。

PDF 去白边 / 手动裁剪

  • 自动去白边：每页单独识别四周白色区域。
  • 统一去白边：分析所选页面后取内容边界并集，多页尺寸更整齐。
  • 手动裁剪：打开预览，用绿色框选择要保留的区域；未框选的 PDF 页保留整页。
  • 安全策略：空白页和极少量边缘内容会保守保留，避免误删。

图片编辑

在“图片处理”中勾选材料后点“裁剪 / 编辑”。支持自由裁剪、1:1、3:4、4:3、A4、16:9，90° 旋转、水平/垂直翻转、自动识别白边、方向键微调与批量应用。编辑方案不会写回原图。

扫描 PDF 压缩的限制

重要：扫描重建会丢失可搜索文本层、表单、超链接和数字签名。需要验签或保留电子签章验证能力的证明材料，不要使用此模式。

第一次运行建议

  1. 完整解压软件 ZIP。
  2. 先双击 运行自检.cmd。它会用软件包里的合成样本验证图标、200 KB 自定义限制、图片裁剪以及 Windows.Data.Pdf。
  3. 自检通过后再处理正式材料。
  4. 招聘网站上传前仍然要放大检查姓名、证件编号、小字、签字和印章。

运行要求

Windows 10 / 11 x64；需要 Microsoft Edge 或 Google Chrome。运行成品不需要安装 Go、Python、Node.js、Ghostscript 或 ImageMagick。本程序未附带商业代码签名证书，因此某些电脑第一次运行时可能显示 Windows SmartScreen 提示。
