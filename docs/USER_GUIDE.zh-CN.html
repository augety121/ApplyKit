第一次使用

解压后，打开 ApplyKit.exe

目标系统为 Windows 10 / 11 x64。正常运行不需要安装 Python、Go 或额外 PDF 转换器；软件使用系统的 Windows PowerShell 5.1、WPF 与 PDF 组件。

完整解压软件包 → 双击 ApplyKit.exe → 选择功能 → 添加文件 → 开始处理

先用随包 测试样本/crop-demo.pdf 验证。它有三页，第 3 页故意全白，第 2 页右下有需要保留的浅色标记。也可运行 运行自检.cmd 检查本机系统组件。

本构建的测试边界：47 项 Go 核心测试、竞争检测、Windows 编译和独立样本检查已完成；当前交付环境不是 Windows，尚未运行 Windows 界面、原生脚本解析及系统 PDF 转换。随包自检脚本需要在你的 Windows 上实际运行，不能将“附有脚本”视为“真机验收通过”。

本构建未做代码签名。遇到安全提示或组织策略阻止，不要关闭防护；先核验来源、源码及校验值，受管电脑按组织要求处理。

PDF 留白裁剪，再导出图片

在左侧选择 PDF 转图片，加入 PDF。右侧的“页面裁剪”提供四种模式。默认不裁剪。

模式作用
不裁剪保留整页，再执行图片导出和大小校验。
自动去白边每页分别识别四周空白，默认留 2mm 安全边距。
统一内容边界同一份 PDF 所选页的内容区域取并集。纸张同尺寸时保持相同裁剪范围；不同尺寸或横竖版不强行拉伸。空白页仍保留整页。
手动框选拖动绿色框精确选择需要保留的区域，支持当前页和本 PDF 全部页。

快速自动裁剪

PDF 转图片 → 添加 PDF → JPG → 2MB → 200 DPI → 自动去白边 → 开始处理

默认阈值 250 适合常见白底材料。“仅纯白”更保守；更宽松的去白边可能忽略极浅标记。浅色页脚、签字或印章必须人工核对，不能以自动判断代替审核。

手动框选

先在文件队列中选中一份 PDF，点击 打开裁剪预览 / 手动框选…。左侧选择页，中间显示原页与绿色保留框，右侧显示裁剪结果。

在页面上拖动可重画框；拖动边缘或四角调整尺寸。打开“移动现有框”后，可在框内拖动平移；点击页面后用方向键微调，Shift 配合方向键作较大调整。也可以输入左、上、右、下的百分比边界，再点击更新。

“应用到本 PDF 全部页”会将当前框按页面比例用于本 PDF 各页，并清除已有的单页覆盖；之后仍可逐页调整。注意横竖版混排、页脚和印章位置不同的材料。点击 保存裁剪方案 返回主界面，再点击 开始处理。

关闭或取消预览不会提交草稿。手动方案只保存在当前会话，退出软件即清除；多份 PDF 需要分别保存方案。源文件内容变化后，旧方案会被拒绝，需要重新预览。

裁剪只改变输出图片。原 PDF 不修改。自动模式不会删除空白页，也不会把页面中间的空白抽掉后重新排列文字。预览用于选择位置，正式导出会按设置的 DPI 重新渲染；裁剪后才压缩和校验实际字节数。

“2M 以内”按字节检查

默认上限是 2,000,000 字节，严格小于；新生成文件以 1,900,000 字节为安全目标。也可选择 1MB、500KB、200KB 或自定义上限。PDF 转图片逐张检查；图片合并 PDF 则检查整份 PDF。

图片压缩和扫描版 PDF 压缩必须比输入文件更小。做不到，但原件已在上限内时，保留原始字节并显示“保留原件”；原件超限且无法满足要求时显示失败，不把超限或变大的结果当成成功。

PDF 转图片、图片转 PDF 属于格式转换，不保证天然小于输入。可开启 转换结果也必须小于输入总量：PDF 转图片比较导出图片合计与原 PDF；图片合并 PDF 比较整份输出与输入图片合计。条件无法满足时不输出假合格结果。

大小达标不等于文字清楚，也不等于报名系统必然接受。提交前放大检查姓名、编号、细字、签字和印章。裁去白边减少像素，不保证编码后按同比例减小，更不会无限降低清晰度来伪造达标。

其他功能与输出位置

功能说明
图片压缩批量 JPG / JPEG / PNG / 静态 GIF；支持自动方向处理和白底合成。动态 GIF 拒绝处理，避免静默丢帧。
图片合并 PDF按队列顺序合并，使用上移/下移调整页序。结果是无可搜索文本层的图像型 PDF。
扫描版 PDF 压缩保留全部页，栅格化重建。会丢失文本层、链接、表单和数字签名，需单独确认。需要验证电子签章的材料不要使用此模式。

默认输出到桌面的“投递材料输出”，每次创建独立子目录，不覆盖原材料。结果列表显示状态、实际字节数与说明；任务会保存 JSON / CSV 报告，可选打包 ZIP。

单批最多 200 个文件，单输入最多 250MB，图片最多 3200 万像素，单 PDF 最多 200 页。未提供 OCR、自动纠偏或文档中间空白重排。

本地处理、缓存与排错

程序不提供登录、上传、遥测或自动更新；正常转换无需联网。PDF 密码仅用于当前进程，不写进任务 JSON 或命令行。不是安全隔离沙箱，不建议打开来历不明的文件。

嵌入的界面和渲染脚本解压到 %LOCALAPPDATA%\ApplyKit\，启动日志位于对应版本缓存目录的 startup.log。任务、渲染与裁剪临时文件使用 %TEMP%\ApplyKit-session-*、%TEMP%\ApplyKit-render-*、%TEMP%\ApplyKit-crop-*。正常结束会尝试清理；崩溃、强制结束或系统文件占用可能留下残留，清理前先关闭软件。

“保留原件”意味着复制原字节，原有元数据也会保留，不是匿名化。处理报告可能含本机路径；提交问题前先脱敏，不要把简历、证件、成绩单或密码公开到 GitHub。

无法启动或转换失败

先完整解压到你有读写权限的普通目录，尝试合成样本。运行 运行自检.cmd，它会在桌面生成独立自检目录与 self-check-report.json。检查其中实际成功/失败项，再结合启动日志定位组件、密码、路径或组织策略问题。不要为了通过测试关闭安全软件。

自检不取代人工检查裁剪框拖拽、屏幕缩放及真实材料。源码的 docs/RELEASE_CHECKLIST.md 提供进一步验收清单。
