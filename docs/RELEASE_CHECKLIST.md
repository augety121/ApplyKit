# 发布前验收

## 自动检查

- [ ] 使用当前受支持的 Go 稳定版本重新构建。
- [ ] `go test -count=1 ./...`、`go vet ./...` 与 race 检查通过。
- [ ] Windows PowerShell 5.1 原生冒烟测试通过，保留真实运行记录。
- [ ] 版本号、COFF 资源、CHANGELOG、标签一致。
- [ ] 解压发行 ZIP 后运行，而不只在源码目录测试。
- [ ] 软件 ZIP 包含 EXE、使用说明、许可证、合成样本、自检脚本和校验和。

## 人工交互

- [ ] 100%、125%、150%、200% 显示缩放下主窗口和裁剪窗口不遮挡按钮。
- [ ] 添加/拖放 PDF、单页与多页、页码选择、中文和空格路径可用。
- [ ] 手动框可新建、调整四角/边缘、平移，箭头键微调，百分比输入有效。
- [ ] 翻页后框选仍正确；当前页覆盖整份 PDF 的统一框。
- [ ] 保存生效，取消不修改旧方案，清除方案恢复完整页面。
- [ ] 预览与正式导出的坐标一致；不同 DPI 不错位。
- [ ] 自动模式保留边缘印记；“仅纯白”模式核对淡灰内容。
- [ ] 全白页未删除，统一裁剪没有取交集造成内容缺失。
- [ ] 合并后的 PDF 页数、页序、尺寸和实际大小正确。
- [ ] 不可达的大小目标显示失败，不输出超限或变大的“压缩成功”文件。
- [ ] 加密 PDF 的正确密码、错误密码和取消路径有明确反馈。
- [ ] 正常退出清理临时预览；原始输入文件 SHA-256 没有变化。

## 发布描述

未完成的检查应明确标注。禁止将 Linux 单元测试、模拟渲染测试或 XAML XML 解析写成“Windows 真机全流程通过”。当前发行构建没有代码签名，应说明这一点。
