当前构建环境为 Linux amd64，Go 1.23.2；没有 Windows、Windows PowerShell 5.1、WPF 或 Windows.Data.Pdf。因此以下项目尚未验收：Windows 启动、PowerShell 原生语法解析、实际 WPF 加载与鼠标拖拽、WinRT PDF 端到端转换、多显示器/缩放、Windows 安全策略兼容性。XML 静态检查不能替代这些检查。

## 在 Windows 上验证

使用免安装包：完整解压后双击 `运行自检.cmd`。它只处理随包合成样本，输出到桌面的 `ApplyKit_自检_...` 文件夹，留下 `self-check-report.json`。最终应为 `success: true`，各项 `status: passed`；失败时不要把软件用于正式提交。

使用源码：先构建，再运行：

```powershell
powershell.exe -NoLogo -NoProfile -STA -ExecutionPolicy RemoteSigned -File .\tools\windows_smoke.ps1
```

该脚本会检查实际内嵌脚本的 PowerShell 解析、WPF 加载、原生 PDF 自动/统一/手动裁剪、预览、图片合并 PDF 和原件字节不变。鼠标操作、视觉排版和具体材料仍需人工验收，详见 `docs/RELEASE_CHECKLIST.md`。

本次交付构建使用了环境中已有的 Go 1.23.2。公开正式发布应从源码使用当时受支持的 Go 稳定版重建；仓库工作流使用 `stable`，但未在本交付环境运行。重新构建后的哈希、字节数与本包可能不同。

## 已知产品限制

自动识别仅去四周空白，不重排正文中间空白；非纯白阈值可能忽略极浅内容，正式提交前必须核对。全白页不自动删除；不同页尺寸不会被统一模式拉伸为相同像素尺寸。手动框只保存在当前会话，不跨重启保存。

扫描版 PDF 压缩输出图像型 PDF，会丢失文本层、链接、表单和数字签名；需要验证电子签章的材料不要采用这个模式。动态 GIF 不支持。没有 OCR、自动纠偏或对任何报名平台的通过保证。

原件保留不是匿名化；复制原字节会保留其元数据。临时文件可能在崩溃后残留，报告可能含本机路径。不要公开私人材料或未脱敏日志，不要为了启动软件关闭系统防护。
