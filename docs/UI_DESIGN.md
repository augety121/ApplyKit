# ApplyKit 2.2 桌面界面

以浅蓝白参考图为视觉方向，保留真实可用的四种工具。品牌、导航、横幅、文件队列和右侧预览形成固定层次；不展示未实现的付费版、工具箱或窗口控制按钮。

桌面主区域使用 CSS Grid；底部输出与任务栏占独立网格行。队列、结果和导出设置各自滚动，避免长内容推挤固定操作区。材料与结果使用可访问的标签切换。宽度不足 1100 px 时导航收起文字；不足 900 px 时工作区按纵向排列；高度不足 820 px 时缩短横幅与预览。

`web/app.css` 保留公共控件和编辑器样式；`web/desktop.css` 是唯一桌面布局与主题覆盖文件，已移除多层叠加的 `v21.css`。颜色统一使用 light/dark 变量。表格最小列宽可收缩，文件名省略显示并保留完整 title。

自动裁剪预览使用后端白边检测接口。侧栏和编辑器共用 `geometry.mjs` 的旋转/翻转变换。PDF 元数据单位为 point（72/in），按所选 DPI 显示预计渲染尺寸。统一裁剪明确说明需在导出时计算所选页并集。

截图全部来自真实运行页面及内置合成样本，不使用模拟文件状态。
